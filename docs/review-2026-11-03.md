## Findings that changed implementation

* A quoted fictional sentence is valid narration. Attributed real-thinker quotations still require evidence.
* Narration dictionaries must contribute their text, never Python dictionary representations.
* Repeating each outline point across several expansion requests caused repeated explanations and premature resolutions. Each outline point now expands once, with all preceding events and the remaining outline supplied as context.
* Phone messaging must map to a phone performance, rather than a book or an unsupported desk-typing pose.
* Approaching another character must stop beside them. The blocking compiler now preserves a minimum horizontal separation.
* A stopped walk could retain the swing foot from the last gait phase. Starts and stops now blend toward the grounded base pose.
* Writing tests now check the actual IK endpoint, including left-facing characters and lap/desk surfaces.
* Cast defaults apply by character kind, not only the literal ID "friend".
* Thumbnail arrays may be word tokens or alternative captions. One caption is selected instead of concatenating multiple concepts.
* End-card characters must stay clear of the centered caption and buttons.
* Encoded-frame publishing uses the numeric source run and preserves earlier preview files.

## Performance evidence

* Full-length narration: 37 passages, 229 seconds of speech, 17.5 minutes of CPU production including verification.
* ACE-Step: a 45-second original score generated in 4.2 minutes on CPU. The score loops with crossfades. An earlier long request exceeded ACE-Step's upstream 600-second timeout, so generation is bounded by default.
* Local Qwen3 4B: earlier outline probe measured about 3.32 generated tokens/s on four CPUs; a complete local-only long-form writing pass is not established.
* Native picture rendering completed in four bounded, parallel GitHub-hosted CPU jobs. No uncompressed frame sequence is retained.

## Current acceptance boundary

The renderer, narration, sound mix, captions, thumbnail generation and artifact packaging have all produced verified playable outputs. That does not certify every screenplay or every physical interaction.

The second fresh full-length review is [41671268205](https://github.com/justsomeoneretarded/pholosophy-psyche-stickman/actions/runs/41671268205); inspect its conclusion and artifacts before claiming it passed.

Complex arbitrary object handovers, general collision-free composed scenes, vertical production, full local-only long-form writing and repeatable editorial quality remain unverified. Audio was reviewed using independent transcription, synchronization and loudness evidence; direct listening was not available in this session.
